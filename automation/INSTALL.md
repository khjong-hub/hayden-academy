# GitHub 업로드 방법

이 파일 세트는 기존 `hayden-academy`에 **추가 업로드**하는 v0.4 자동화 골격입니다.

1. ZIP 압축 해제
2. GitHub `hayden-academy` → `Add file` → `Upload files`
3. `.github`, `scripts`, `automation`, `data` 폴더를 업로드
4. `Commit changes`
5. `Actions` 탭에서 Daily / Weekly / Monthly workflow 확인
6. 각 workflow에서 `Run workflow`로 수동 테스트

주의:
- `.github` 폴더도 반드시 업로드합니다.
- 이 버전은 실제 뉴스/AI 콘텐츠가 아니라 자동화가 작동하는지 검증하는 scaffold입니다.
- 테스트가 성공하면 다음 버전에서 뉴스 수집과 AI 편집을 연결합니다.
