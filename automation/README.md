# HAYDEN ACADEMY v0.4 · Automation

## 현재 자동화
- Daily: 매일 07:00 KST
- Weekly: 매주 월요일 07:10 KST
- Monthly: 매월 1일 07:20 KST

다음 단계:
1. 뉴스/RSS/공식기관 수집
2. 중복·저품질 제거
3. Hayden 관련성 평가
4. AI editorial analysis
5. Daily → Weekly → Monthly 누적 분석
6. 이메일/알림
