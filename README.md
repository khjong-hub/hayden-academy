# HAYDEN ACADEMY

GitHub Pages-ready personal learning portal.

## Deploy
1. Create a GitHub repository.
2. Upload all files/folders in this directory to the repository root.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Save and open the generated Pages URL.

## Important
Do not put real family financial data in this public repository. Family Money is currently a concept/public shell. The shared private version should later use authentication + a private database.
